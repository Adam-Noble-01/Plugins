Naming Prefixes (Quick Name)

Each prefix becomes a button in the Outliner tab's Quick Name panel (the Name button on the table's left, or Q). Name it exactly gives the selected objects that name (CAD__FrontElevation); Put in front keeps their names after it (REF__SideElevation). Elevation face sets the face segment inside a name (SUB__Orangery__DoorHandle__Front__01), with the cardinal after it once the model's orientation is set. Quick Name only ever changes names, never tags. Agents read the meaning with agent_outliner prefixes, so write it as an instruction.

Flag Types

A flag marked waits for an agent puts the object in the agent inbox (agent_outliner inbox) until an agent acknowledges it or the thread is resolved. The id is stored on flagged objects: keep it once in use.

Copy for Agent: Closing Note

The last paragraph of the text Copy for Agent puts on the clipboard: how the agent should answer.

Agents are told apart from you by the Na SketchUp MCP's own code on the call stack: anything an agent does through the MCP (ruby_eval included) is the agent's. History is kept on this PC beside the model, never inside it, so tracking adds no undo steps and never marks the model as changed.

Colour Grading

A new or changed object is tinted in the colour of who did it, strongest at first, fading through four bands. Past the last band it is plain again; the second band is what Recent means.

Selecting

Agent Bridge

Agents start with agent_outliner {action: "summary"}, read what waits for them with inbox, what you changed with changes (by: "user"), what each standard name means with prefixes, and answer with agent_outliner_edit (reply, comment, flag, resolve, acknowledge, name). Their comments and flags show here in the agent colour.
