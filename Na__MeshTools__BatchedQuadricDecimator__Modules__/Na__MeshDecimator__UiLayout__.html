Batched Quadric Decimator

v0.0.4  ·  Adam Noble / Noble Architecture

What it does

Reduces the polygon count of selected SketchUp groups using the Quadric Error Metric (QEM) algorithm — the same technique used by professional 3D tools like MeshLab and Maya.

Each edge collapse preserves surface shape by minimising the summed plane-distance error at every vertex, producing cleaner, more accurate simplifications than naive face-count reduction.

How to use

  1. 1Select one or more SketchUp groups in the viewport (or run inside a group context).
  2. 2Switch to the Decimation tab and set your target percentage and options.
  3. 3Click Run Decimation. Progress is shown in the status bar.
  4. 4Switch to the Statistics tab to review before/after counts. Results accumulate across runs so you can compare settings.
  5. 5Use Edit → Undo if the result is not satisfactory.

Tips for best results

Start conservative: 25% reduction is the default. Increase gradually — 50–70% is usually safe for background objects.

Border edges: Keep "Maintain open border edges" on for watertight meshes; turn it off only for fully closed solids.

Materials: "Preserve material boundary edges" prevents edges between different materials from being collapsed, avoiding texture seam artefacts.

Performance: For very dense meshes (> 50k triangles) reduce "Max candidate edges" to 5000 to keep each pass fast.

Hot reload: After editing Ruby source files, use the Settings → Reload Scripts button to reload without restarting SketchUp.
